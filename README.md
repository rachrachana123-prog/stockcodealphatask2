## ⚙️ How It Works

The Stock Portfolio Tracker is a simple Python-based application that allows users to manage and track their stock investments.

The program works by taking user input such as stock name, quantity of shares, and price per share. This data is stored using Python data structures like lists and dictionaries.

The application then processes this data to calculate important values such as:
- Total investment for each stock
- Overall portfolio value
- Profit or loss (if applicable)

Using loops, the program iterates through all the stocks in the portfolio and performs the required calculations. Conditional statements (if-else) are used to determine scenarios such as profit or loss.

The results are then displayed in a clear and organized format, helping the user understand their portfolio performance.

This project demonstrates how basic programming concepts can be used to build a simple financial tracking system.
